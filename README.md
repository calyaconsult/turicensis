# turicensis
*Thomas Turicensis - Intellektuelle Sackgassen*

The book presented here was generated by Anthropic's `Claude Sonnet 5`

Its author `Thomas Turicensis` does not exist, nor does the publisher `Hämmerli & Nagler, Zürich`

The purpose of this book is to test the usefulness and limitations of AI in the process of book production.

The LLM "Claude" did not only write the entire text but it also provided the CSS that made the text printable.

We are uploading the text to GitHub in order to establish the *terminus post quem* for any versions or derivatives of this text.

As a text wholly generated by a machine, it does not enjoy copyright protection. This means you, whoever you may be, are free to use it in any way you want. What you cannot do, however, is claim that it is **yours** since it is not and this repository proves that it is not.
